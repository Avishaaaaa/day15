# React Basics

This repository contains the work I completed while learning the fundamentals of React.js. Instead of only studying the concepts, I practiced them by building small components and examples to understand how React works.

The main goal of this repository is to strengthen my understanding of React and build a solid foundation before moving on to larger projects.

## Concepts Covered

- Functional Components
- JSX
- Props
- State using `useState`
- Event Handling
- Rendering Lists using `map()`
- Conditional Rendering
- Basic React Project Structure

## Technologies Used

- React.js
- JavaScript (ES6)
- JSX
- Vite
- HTML
- CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/react-basics.git
```

Move into the project folder:

```bash
cd react-basics
```

Install the required dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in the terminal to view the project in your browser.
